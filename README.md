Repository ini digunakan untuk menyimpan hasil penyelesaian tugas pada fase pertama dan fase kedua. Pada fase pertama, hasil pengerjaan disatukan dalam satu dokumen PDF, sedangkan pada fase kedua dikumpulkan dua program yang dibuat menggunakan bahasa C++. Repository ini dikelola oleh Eugell Revaldo Efraim dari kelompok Copper sebagai media pengumpulan tugas sesuai dengan ketentuan yang diberikan.
